# 기획서: 로또 번호 생성기 (React)

## 1. 개요

`day12/mylotto`(HTML/CSS/JS + Bootstrap)로 만들었던 로또 번호 생성 앱을 React로 다시 만든다.
기능은 그대로 두고, 화면을 컴포넌트로 나누고 상태를 스토어 하나에서 관리한다.

- 로또 6/45 번호를 **자동·수동·반자동**으로 5세트(A~E) 생성
- 자동 생성에서 뺄 **제외 번호** 선택
- 화면 상단에 **지난주 당첨번호** 표시
- 생성 결과는 **줄마다 복사·초기화**, 전체 초기화 가능

참고 문서: `day12/app_lotto.md` (기존 앱 PRD)

## 2. 기술 스택

`react-apps/CLAUDE 복사본.md` 가이드를 따른다.

| 항목 | 내용 |
|---|---|
| 빌드 도구 | Vite (`npm create vite@latest my-app02 -- --template react`) |
| 언어 | React 19 + JavaScript (TypeScript 사용 안 함) |
| CSS | Tailwind CSS v4 (`tailwindcss`, `@tailwindcss/vite`) |
| 상태 관리 | Zustand (`src/stores/`) |
| 린트 | oxlint (`no-unused-vars` 끔) |
| 개발 서버 | 포트 3000, 시작 시 브라우저 자동 열림 |

기존 앱과 달라지는 점:
- Bootstrap 대신 Tailwind로 같은 화면을 만든다 (가이드 기준).
- Bootstrap Icons 대신 글자 아이콘(✕, ↺, ⧉)을 쓴다. 아이콘 라이브러리는 추가하지 않는다.
- 당첨번호는 최신 회차인 **제1245회**로 바꾼다.

## 5. 기능 요구사항

### F1. 지난주 당첨번호 (②)

- `service/latestDraw.js`에 최신 회차 정보를 상수로 저장해 보여준다. 외부 API는 호출하지 않는다 (동행복권 API는 브라우저에서 CORS로 막힘).
- 표시: 회차, 추첨일, 당첨번호 6개(공), `+`, 보너스, 1등 당첨자 수와 1인당 당첨금(`약 30억 651만원` 형식)
- 오늘 날짜로 계산한 최신 회차가 저장된 회차보다 크면 "최신 회차 정보가 아닐 수 있어요"를 회색 작은 글씨로 보여준다.
  - 1회 = 2002-12-07(토), 매주 토요일 20:45 추첨. 추첨 전이면 전 주 토요일 기준.

```js
// 2026-10-12 검색 기준
export const LATEST_DRAW = {
    round: 1245,
    date: '2026-10-10',
    numbers: [4, 5, 25, 28, 32, 42],
    bonus: 12,
    firstPrizeWinners: 10,
    firstPrizeAmount: 3006515775,   // 1인당 30억 651만 5775원
};
```

### F2. 번호 선택 (③)

- 모드 전환 버튼 2개: **수동 번호**(기본, 파랑) / **제외 번호**(빨강). 선택된 모드는 색이 채워진다.
- 안내 문구
  - 수동: "번호를 눌러 수동 번호를 골라주세요 (최대 6개)."
  - 제외: "자동 생성에서 뺄 번호를 눌러주세요."
- 1~45 번호판(9열). 누르면 현재 모드에 따라 선택/해제.
  - 수동 선택: 파란 배경, 흰 글씨
  - 제외 선택: 연한 빨간 배경, 빨간 글씨, 취소선
- 규칙
  - 수동 번호는 최대 6개
  - 제외 번호는 최대 39개 (최소 6개는 남아야 함)
  - 한 번호는 수동과 제외에 동시에 들어갈 수 없다. 한쪽에서 고르면 다른 쪽에서 빠진다.
- 현황: `수동: 7, 14` / `제외: 1, 2` (오름차순, 없으면 "없음")
- 버튼
  - **수동 게임 추가**: 고른 번호(1~6개)를 수동 게임으로 등록하고 선택을 비운다.
  - **수동 초기화**: 고르고 있는 수동 번호만 비운다.
  - **제외 초기화**: 제외 번호를 비운다.

### F3. 수동 게임 목록 (④)

- 제목 `수동 게임 (n/5)`, 도움말 "6개 미만으로 고르면 나머지는 자동으로 채워져요 (반자동)."
- 각 줄: 라벨(A~E), 종류(6개 = 수동, 1~5개 = 반자동), 공 6칸(빈 칸은 회색 `?`), 삭제(✕)
- 삭제하면 아래 게임이 올라오고 라벨이 다시 붙는다.
- 비어 있으면 "추가된 수동 게임이 없어요 (전부 자동으로 생성)"

### F4. 번호 생성 (⑤) — 비어 있는 줄만 채운다

- 결과는 A~E 5줄, 각 줄은 비어 있음(`null`) 또는 번호 6개
- "번호 생성"을 누르면 **비어 있는 줄만** 채운다. 이미 있는 줄은 그대로 둔다.
- 줄 i를 채울 때
  - 수동 게임 i번째가 있으면 그 번호를 고정하고 나머지를 랜덤으로 채운다 (종류는 수동/반자동)
  - 없으면 6개 모두 랜덤 (종류 **자동**)
  - 랜덤 후보 = 1~45 − 제외 번호 − 이미 들어간 번호, 중복 없이 뽑음
  - 오름차순 정렬
- 빈 줄이 없으면 안내: "비어 있는 줄이 없어요. 줄 초기화나 전체 초기화 후 생성해 주세요."

### F5. 생성 결과 (⑥)

- 각 줄: 라벨, 종류 배지(비어 있으면 `-`), 공 6개, **복사**(⧉), **줄 초기화**(↺)
- 수동 게임에서 온 고정 번호는 파란 링으로 표시
- 5줄 모두 비어 있으면 "번호 생성 버튼을 눌러주세요"
- **줄 초기화**: 그 줄만 비운다. **전체 초기화**: 5줄 모두 비운다. 둘 다 수동 게임·수동 번호·제외 번호는 남긴다.
- **복사**: `3, 7, 14, 23, 32, 40` 형식으로 클립보드에 복사하고 "A줄 번호를 복사했어요: …" 안내
  - `navigator.clipboard`를 못 쓰면 임시 `textarea` + `execCommand('copy')`로 복사
  - 빈 줄이면 "비어 있는 줄은 복사할 수 없어요."
- 모바일(320px까지)에서도 공 6개와 버튼 2개가 한 줄에 들어간다.

### F6. 로또 공

| 번호 | 색상 |
|---|---|
| 1~10 | `#fbc400` |
| 11~20 | `#69c8f2` |
| 21~30 | `#ff7272` |
| 31~40 | `#aaaaaa` |
| 41~45 | `#b0d840` |

- 원형, 흰 글씨, 굵게. 당첨번호 40px / 게임 줄은 최대 36px이고, 좁은 화면에서는 줄 너비에 맞춰 작아진다 (320px 화면에서 약 23px)
- 고정 번호: 파란 링(`ring-2 ring-blue-600 ring-offset-2`)
- 빈 칸: 연회색 배경, 회색 `?`

## 6. 상태 설계 (`stores/lottoStore.js`)

```js
{
    mode: 'pick',                 // 'pick' | 'exclude'
    picked: [],                   // 고르고 있는 수동 번호
    excluded: [],                 // 제외 번호
    manualGames: [],              // [[7, 14], [1, 2, 3, 4, 5, 6]]
    results: [null, null, null, null, null],
    // results[i] = null 또는 { type, numbers, fixed }
    message: null,                // 토스트 { id, text }

    setMode, toggleNumber, addManualGame, removeManualGame,
    clearPicked, clearExcluded,
    generate, resetRow, resetAll, copyRow,
    showMessage, hideMessage,
}
```

- 컴포넌트는 필요한 값과 함수만 `useLottoStore(s => s.xxx)`로 꺼내 쓴다.
- 랜덤 생성·회차 계산·복사 같은 순수 로직은 `service/lottoService.js`에 두고 스토어가 불러 쓴다.

## 7. 예외 처리

| 상황 | 안내 메시지 |
|---|---|
| 수동 번호 7개째 | 수동 번호는 최대 6개까지 고를 수 있어요. |
| 제외 후 6개 미만 남음 | 최소 6개 번호는 남겨주세요. |
| 수동 번호 0개로 추가 | 수동 번호를 1개 이상 골라주세요. |
| 수동 게임 6개째 | 수동 게임은 최대 5개까지 추가할 수 있어요. |
| 빈 줄 없이 생성 | 비어 있는 줄이 없어요. 줄 초기화나 전체 초기화 후 생성해 주세요. |
| 빈 줄 복사 | 비어 있는 줄은 복사할 수 없어요. |
| 복사 실패 | 복사하지 못했어요. 번호를 직접 선택해서 복사해 주세요. |

수동 게임 번호가 나중에 제외 번호가 되면 수동 번호를 우선한다 (그대로 고정).

## 8. 완료 기준

- [ ] `npm run dev` → 3000번 포트로 열리고 콘솔 에러가 없다.
- [ ] `npm run build`, `npm run lint`가 에러 없이 끝난다.
- [ ] 폴더 구조가 가이드(pages / comp / service / utils / stores)를 따른다.
- [ ] 제1245회(4, 5, 25, 28, 32, 42 + 12)가 색깔 공으로 보인다.
- [ ] 아무것도 고르지 않고 생성하면 5줄 모두 "자동", 중복 없이 오름차순이다.
- [ ] 제외 번호는 자동·반자동 번호에 나오지 않는다 (여러 번 생성해서 확인).
- [ ] 7, 14 수동 게임 → A줄 "반자동", 7·14에 파란 링
- [ ] 6개 수동 게임 → 그 번호 그대로 "수동"
- [ ] C줄만 초기화 후 생성하면 C줄만 바뀐다.
- [ ] 복사 버튼으로 줄 번호가 복사된다. 빈 줄은 안내만 뜬다.
- [ ] 5줄이 다 찼을 때 생성하면 안내가 뜨고 결과는 그대로다.
- [ ] 초기화해도 수동 게임과 제외 번호는 남는다.
- [ ] 320px 너비에서도 가로 스크롤이 없고 결과 줄이 한 줄로 보인다.

## 9. 범위 밖

당첨번호 실시간 조회, 당첨 확인, 번호 저장(localStorage), 로그인
