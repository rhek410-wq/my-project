# 기획서: app-board — MAISON ÉLAN 액세서리 쇼핑몰 (React)

## 1. 개요

목걸이·귀걸이·팔찌·반지를 판매하는 **액세서리 쇼핑몰** 웹 앱이다.
`react-apps02/app-board`(mock-board를 실제 서버에 연동한 게시판)를 복사해서 만들었다.

- 브랜드명: **MAISON ÉLAN** (가상 브랜드)
- 디자인 무드: 심플하지만 고급스럽게. 영어 메뉴, 아이보리 바탕 + 먹색 글자 + 옅은 골드 포인트
- 상단 메뉴 배열은 참고 쇼핑몰(didierdubot.co.kr)과 같은 순서로 구성
- 상품 사진은 넣지 않고, 카테고리별 선화 일러스트(SVG)로 대신한다

### 데이터 출처

| 데이터 | 출처 | 비고 |
|---|---|---|
| 회원가입·로그인·회원정보 | **실제 서버** (Spring Boot, JWT) | `../../react-apps02/FRONTEND_API_PROMPT.md` 명세 |
| Q&A 게시판 | **실제 서버** (board API) | 게시판 API를 고객 Q&A로 사용 |
| 상품 | **mock 서버** (axios-mock-adapter) | 서버에 상품 API가 아직 없음 |
| 장바구니·위시리스트 | **브라우저 저장** (localStorage) | 서버 API 없음 |

- 화면은 항상 **axios**로 REST API를 호출한다. 상품 API만 별도 axios 인스턴스(`shopApi`)에 mock adapter를 붙인다.
- 나중에 실제 상품 API가 생기면 `.env`의 `VITE_USE_PRODUCT_MOCK=false` 로 끄면 된다. 화면·서비스 코드는 고치지 않는다.

## 3. 기능

### 3.1 상단 바 (Header)

```
COMPLIMENTARY SHIPPING ON ORDERS OVER ₩50,000                       ← 공지 띠
MAISON ÉLAN   BEST  NEW IN  SHOP▾  PROMOTION & EVENT  BRAND STORY  CATALOGUE  [QUICK DELIVERY]   SEARCH  LOGIN  ♡  CART (n)
```

- 메뉴 순서는 참고 쇼핑몰과 같다: **BEST · NEW IN · SHOP · PROMOTION & EVENT · BRAND STORY · CATALOGUE · [QUICK DELIVERY]**
- **SHOP**에 마우스를 올리면 메가 메뉴가 열린다
  - Item: All Jewelry / Necklaces / Earrings / Bracelets / Rings
  - Collection: Lumière / Aube / Étoile / Perle / Signature / Jardin
- 오른쪽 유틸 메뉴: SEARCH · LOGIN(로그인 시 MY PAGE · LOGOUT) · ♡ 위시리스트(개수 배지) · CART(수량)
- **SEARCH** 클릭 → 전체 화면 검색 오버레이 (인기 검색어, 컬렉션 바로가기, ESC로 닫기)
- 1280px 미만에서는 햄버거 메뉴로 바뀐다
- 헤더는 스크롤해도 상단에 고정된다

### 3.2 홈

1. 히어로: 사진 없이 큰 세리프 타이포그래피 (“Quiet light, worn every day.”) + NEW IN / SHOP ALL 버튼
2. 카테고리 타일 4개 (Necklaces · Earrings · Bracelets · Rings)
3. Best Sellers 4개
4. 브랜드 소개 띠
5. New In 4개
6. 컬렉션 6개 카드

### 3.3 상품 목록

| 메뉴 | 경로 | 조건 |
|---|---|---|
| BEST | `/best` | 판매량 상위 12개 (기본 정렬: 인기순) |
| NEW IN | `/new` | 최근 등록 12개 |
| SHOP | `/shop`, `/shop/:category` | 전체 / 카테고리별, 카테고리 탭 표시 |
| PROMOTION & EVENT | `/promotion` | 할인 상품 |
| CATALOGUE | `/catalogue`, `/catalogue/:collection` | 컬렉션별, 컬렉션 탭 + 소개문 |
| [QUICK DELIVERY] | `/quick` | 당일 출고 상품 |
| 검색 | `/search?q=` | 상품명·컬렉션·소재·스톤·품번 부분일치 |

- 공통 필터: **소재**(14K Gold, 10K Gold, Silver 925, 18K Gold Plated), **가격대**
- 정렬: New · Popular · Price: Low · Price: High · Name · Reviews
- 12개씩 페이징. 필터·정렬·페이지는 URL 쿼리에 저장 (새로고침·뒤로가기 유지)
- 상품 카드: 일러스트, ♡ 버튼, 컬렉션명, 상품명, 가격(할인율·정가 취소선), New/Best/Quick 배지

### 3.4 상품 상세 (`/product/:id`)

- 일러스트, 컬렉션, 상품명, 품번, 가격, 평점·리뷰 수, 설명
- 옵션 선택: 반지 → Size(#7~#15), 목걸이·팔찌 → Length, 귀걸이 → 옵션 없음
- 수량 선택(1~99) → 합계 금액
- **Buy Now**(담고 장바구니로 이동) / **Add to Cart** / ♡ 위시리스트
- 옵션을 고르지 않으면 안내 문구 표시
- 같은 컬렉션 상품 4개 추천

### 3.5 장바구니 (`/cart`) · 위시리스트 (`/wishlist`)

- 브라우저(localStorage `maison-shop`)에 저장 → 새로고침해도 유지
- 장바구니: 같은 상품이라도 옵션이 다르면 다른 줄. 수량 변경, 삭제
- 주문 요약: 상품 금액, 배송비(₩50,000 이상 무료, 미만 ₩3,000), 합계
- **Checkout**: 로그인 필요(안 했으면 로그인 화면 → 다시 장바구니). 데모라 실제 결제 없이 확인 후 장바구니를 비운다
- 위시리스트: 담은 상품을 카드 그리드로 표시, ♡ 다시 누르면 빠진다

### 3.6 회원 (실제 서버)

| 기능 | 경로 | API |
|---|---|---|
| 회원가입 | `/signup` | `POST /api/v1/auth/signup` |
| 로그인 | `/login` | `POST /api/v1/auth/login` → accessToken(1시간) 저장 |
| 로그아웃 | 헤더 LOGOUT | 토큰 삭제 (API 없음) |
| 마이페이지 | `/mypage` → `/members/:userId` | `GET /api/v1/users/{userId}` |
| 내 정보 수정 | `/members/:userId/edit` | `PUT /api/v1/users/{userId}` (비밀번호는 바꿀 때만 전송) |
| 회원 탈퇴 | 마이페이지 | `DELETE /api/v1/users/{userId}` |

- 회원가입 입력: 아이디(4~50자), 비밀번호(8~100자) + 확인, 이름(50자 이하), 생년월일, 성별(남자/여자)
- 클라이언트 검증 규칙은 서버 검증과 같다 (`utils/validation.js`)
- 아이디 중복(409) → “이미 사용 중인 아이디입니다.”
- 토큰 만료(401 `AUTH_REQUIRED`) → 자동 로그아웃 후 로그인 화면, 로그인하면 원래 화면으로 복귀
- 마이페이지에서 Wishlist / Cart 바로가기

### 3.7 Q&A 게시판 (실제 서버)

- 푸터 Customer Center의 **Notice · Q&A** 에서 진입 (`/board`)
- 목록·상세는 누구나, 작성·수정·삭제는 로그인 필요 (기존 app-board 기능 그대로)

### 3.8 디자인

| 토큰 | 라이트 | 용도 |
|---|---|---|
| canvas | `#fbf9f5` | 페이지 배경 (아이보리) |
| ink | `#1c1a17` | 글자·주요 버튼 |
| muted | `#7a746b` | 보조 글자 |
| line | `#e6e1d8` | 구분선 |
| gold | `#a8875a` | 할인율·배지 포인트 |

- 영문 제목은 세리프(Cormorant Garamond), 메뉴·버튼·라벨은 대문자 + 넓은 자간
- 모서리는 각지게(둥근 모서리 없음), 그림자 최소화, 여백을 넉넉히
- 입력칸은 밑줄형, 버튼은 검정 채움(주) / 테두리(보조)
- 시스템 다크 모드를 따라 색을 바꾼다 (`index.css`의 `@media (prefers-color-scheme: dark)`)
- 모바일 375px에서 가로 스크롤 없음

## 4. 상품 API 명세 (mock)

에러 형식과 페이지 형식은 실제 서버와 같다: `{ code, message }`, Spring `Page` (`content`, `totalElements`, `totalPages`, `number`(0부터), `size`, `first`, `last`, `empty`).

### `GET /api/v1/products`

| Query | 설명 |
|---|---|
| page / size | 0부터 / 기본 12 |
| sort | `new`(기본) · `name` · `priceAsc` · `priceDesc` · `popular` · `review`. 그 외 → 400 `INVALID_SORT` |
| category | `necklaces` · `earrings` · `bracelets` · `rings` |
| collection | `lumiere` · `aube` · `etoile` · `perle` · `signature` · `jardin` |
| tag | `best` · `new` · `sale` · `quick` |
| material | `14K Gold` · `10K Gold` · `Silver 925` · `18K Gold Plated` |
| minPrice / maxPrice | 판매가 범위 |
| keyword | 부분일치 검색 (대소문자 무시) |

응답 항목 (ProductSummary)
```json
{
  "id": 37, "code": "RG1259", "name": "Jardin Solitaire Ring",
  "category": "rings", "collection": "jardin", "collectionLabel": "Jardin",
  "material": "10K Gold", "stone": "Cubic Zirconia",
  "price": 617000, "discountRate": 20, "salePrice": 493600,
  "salesCount": 512, "reviewCount": 100, "rating": 4.3,
  "quickDelivery": true, "isBest": false, "isNew": true,
  "createdAt": "2026-09-21T00:00:00"
}
```

### `GET /api/v1/products/{id}`
ProductSummary + `description`(설명), `details`(상세 항목 배열). 없으면 404 `NOT_FOUND`.

### `GET /api/v1/products/meta`
`{ categories, collections, materials }` — 필터 UI용 목록.

## 8. 실제 상품 서버로 바꾸는 방법

1. 백엔드에 4장 명세대로 `/api/v1/products` API를 만든다
2. `.env`에 `VITE_USE_PRODUCT_MOCK=false`
3. (선택) `src/utils/mock/` 폴더와 `axios-mock-adapter` 의존성 삭제
4. 장바구니·위시리스트도 서버에 저장하려면 `shopStore.js`의 동작을 API 호출로 바꾼다
