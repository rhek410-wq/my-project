# PRD: 로또 번호 생성기 (app_lotto)

## 1. 개요

로또 6/45 번호를 자동·수동·반자동으로 5세트 생성하는 웹 앱이다.
제외할 번호를 고를 수 있고, 화면 상단에 지난주 당첨번호를 보여준다.

- 대상: 로또를 사는 일반 사용자
- 실행 방식: 브라우저에서 `index.html`을 열면 바로 동작해야 한다 (빌드·서버 없음)
- 참고 프로토타입: `day12/lotto.html` (Bootstrap 없이 만든 1파일 버전. 로직 참고용)

## 2. 기술 스택

| 항목 | 내용 |
|---|---|
| 마크업 | HTML5 |
| 스타일 | Bootstrap 5.3 (CDN) + 직접 작성한 CSS |
| 스크립트 | 순수 JavaScript (ES6, 프레임워크·빌드 도구 없음) |
| 아이콘 | Bootstrap Icons (CDN) |

CDN 링크:

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

## 3. 파일 구조

HTML, CSS, JS를 분리한다.

```
day12/app_lotto/
├── index.html        # 화면 구조 (Bootstrap 컴포넌트)
├── css/
│   └── style.css     # 로또 공, 번호판 등 Bootstrap에 없는 스타일
└── js/
    ├── data.js       # 지난주 당첨번호 데이터
    └── app.js        # 상태 관리, 이벤트, 화면 그리기
```

- `index.html`에서 스크립트는 `</body>` 바로 앞에 `data.js` → `app.js` 순서로 불러온다.
- 인라인 `style`, 인라인 `onclick`은 쓰지 않는다. 스타일은 `style.css`, 이벤트는 `app.js`의 `addEventListener`로 처리한다.
- 코드 주석은 한국어로 짧게 단다.

## 5. 기능 요구사항

### F1. 지난주 당첨번호 표시 (②)

- `js/data.js`에 최신 회차 정보를 상수로 저장해 두고 화면에 보여준다.
- 동행복권 API(`https://www.dhlottery.co.kr/common.do?method=getLottoNumber&drwNo={회차}`)는 브라우저에서 CORS로 막히므로 **호출하지 않는다.** 저장된 데이터만 사용한다.
- 표시 항목: 회차, 추첨일, 당첨번호 6개(공 모양), `+`, 보너스 번호, 1등 당첨자 수와 1인당 당첨금
- 오늘 날짜로 계산한 최신 회차가 저장된 회차보다 크면, 카드 아래에 회색 작은 글씨로 "최신 회차 정보가 아닐 수 있어요"를 보여준다.
  - 회차 계산식: 1회 = 2002-12-07(토). `최신 회차 = floor((마지막 토요일 - 2002-12-07) / 7일) + 1`
  - 토요일 20시 45분 추첨 전이면 그 전 주 토요일을 마지막 토요일로 본다.

`data.js` 예시 (2026-10-05 검색 기준 실제 값):

```js
// 지난주 당첨번호 (새 회차가 나오면 이 값만 바꾸면 된다)
const LATEST_DRAW = {
    round: 1244,
    date: '2026-10-03',
    numbers: [1, 13, 18, 26, 34, 38],
    bonus: 25,
    firstPrizeWinners: 18,
    firstPrizeAmount: 1604690000   // 1인당 약 16억 469만원
};
```

### F2. 번호판과 모드 전환 (③)

- 1~45 번호 버튼을 9열 그리드로 보여준다.
- 위쪽 `btn-group`으로 모드를 전환한다: **수동 번호**(기본) / **제외 번호**
- 모드 아래에 안내 문구를 보여준다.
  - 수동: "번호를 눌러 수동 번호를 골라주세요 (최대 6개)."
  - 제외: "자동 생성에서 뺄 번호를 눌러주세요."
- 번호를 누르면 현재 모드에 따라 선택/해제(토글)된다.

| 상태 | 표시 |
|---|---|
| 기본 | 흰 배경, 회색 테두리 |
| 수동 선택 | 파란 배경(`primary`), 흰 글씨 |
| 제외 선택 | 연한 빨간 배경, 빨간 글씨, 취소선 |

규칙:
- 수동 번호는 최대 6개. 7번째를 누르면 경고를 보여주고 선택하지 않는다.
- 제외 번호는 최소 6개 번호가 남도록 최대 39개까지만 고를 수 있다.
- 한 번호가 수동과 제외에 동시에 들어갈 수 없다. 한쪽에서 고르면 다른 쪽에서 빠진다.
- 번호판 아래에 현재 선택 현황을 보여준다: `수동: 7, 14` / `제외: 1, 2` (오름차순, 없으면 "없음")

버튼:
- **수동 게임 추가**: 고른 수동 번호(1~6개)를 수동 게임으로 등록하고 수동 선택을 비운다.
  - 수동 번호가 0개면 경고: "수동 번호를 1개 이상 골라주세요."
  - 수동 게임이 이미 5개면 경고: "수동 게임은 최대 5개까지 추가할 수 있어요."
- **수동 초기화**: 지금 고르고 있는 수동 번호만 비운다.
- **제외 초기화**: 제외 번호를 모두 비운다.

### F3. 수동 게임 목록 (④)

- 제목에 개수를 표시한다: `수동 게임 (n/5)`
- 각 줄: 라벨(A~E), 종류 배지, 공 6칸(비어 있는 칸은 회색 `?`), 삭제 버튼(✕)
- 종류: 번호 6개 = **수동**, 1~5개 = **반자동** (나머지는 생성할 때 자동으로 채움)
- 삭제하면 아래 게임이 한 칸씩 올라오고 라벨이 다시 붙는다.
- 목록이 비어 있으면 "추가된 수동 게임이 없어요 (전부 자동으로 생성)"을 보여준다.
- 도움말: "6개 미만으로 고르면 나머지는 자동으로 채워져요 (반자동)."

### F4. 번호 생성 (⑤) — 비어 있는 줄만 채운다

결과는 A~E 5줄이고, 각 줄은 **비어 있음** 또는 **번호 6개**다.

- "번호 생성"을 누르면 **비어 있는 줄만** 새로 생성하고, 이미 번호가 있는 줄은 그대로 둔다.
- 처음에는 5줄이 모두 비어 있으므로 5세트가 모두 생성된다.
- 줄 i(0~4)를 채울 때:
  - 수동 게임 i번째가 있으면 그 번호를 고정으로 넣고 나머지를 랜덤으로 채운다. 종류는 수동 게임의 종류(수동/반자동)를 따른다.
  - 없으면 6개 모두 랜덤이고 종류는 **자동**이다.
  - 랜덤 번호는 1~45 중 **제외 번호와 이미 들어간 번호를 뺀 후보**에서 중복 없이 뽑는다.
  - 결과는 오름차순으로 정렬한다.
- 비어 있는 줄이 하나도 없으면 생성하지 않고 안내한다: "비어 있는 줄이 없어요. 줄 초기화나 전체 초기화 후 생성해 주세요."
- 생성 시점의 제외 번호와 수동 게임을 사용한다. 이미 채워진 줄은 나중에 조건을 바꿔도 다시 계산하지 않는다.

### F5. 생성 결과 (⑥)

- 각 줄: 라벨(A~E), 종류 배지(자동/반자동/수동, 비어 있으면 `-`), 공 6개, **복사** 버튼(`bi-copy`), **줄 초기화** 버튼(↺, `bi-arrow-counterclockwise`)
- 수동 게임에서 온 고정 번호는 파란 테두리로 표시해 자동 번호와 구분한다.
- 비어 있는 줄은 회색 `?` 공 6개로 보여준다.
- 처음(5줄 모두 비어 있음)에는 줄 대신 "번호 생성 버튼을 눌러주세요"를 보여준다.

초기화 버튼:
- **줄 초기화**: 그 줄만 비운다. 다른 줄은 그대로다.
- **전체 초기화** (카드 헤더 오른쪽, `btn btn-outline-danger btn-sm`): 5줄을 모두 비운다.
- 두 버튼 모두 생성 결과만 지운다. 수동 게임, 수동 번호, 제외 번호는 그대로 남는다.

복사 버튼:
- 그 줄 번호를 `3, 7, 14, 23, 32, 40` 형식으로 클립보드에 복사하고 "A줄 번호를 복사했어요: …"를 보여준다.
- `navigator.clipboard`를 못 쓰는 환경(`file://`로 열었을 때 등)에서는 임시 `textarea` + `document.execCommand('copy')`로 복사한다.
- 비어 있는 줄이면 복사하지 않고 "비어 있는 줄은 복사할 수 없어요."를 보여준다.
- 모바일(576px 미만)에서도 공 6개와 버튼 2개가 한 줄에 들어가야 한다 (게임 줄의 공은 26px).

### F6. 로또 공 스타일

동행복권과 같은 번호대별 색상을 쓴다. 공은 원형, 흰 글씨, 굵게.

| 번호 | 색상 |
|---|---|
| 1~10 | `#fbc400` (노랑) |
| 11~20 | `#69c8f2` (파랑) |
| 21~30 | `#ff7272` (빨강) |
| 31~40 | `#aaaaaa` (회색) |
| 41~45 | `#b0d840` (초록) |

- 크기: 기본 40px, 모바일(576px 미만) 32px
- 고정 번호 표시: `outline: 3px solid` primary 색, `outline-offset: 2px`
- 빈 칸: 연회색 배경, 회색 `?`

## 7. 함수 목록 (`app.js`)

| 함수 | 역할 |
|---|---|
| `init()` | 번호판 생성, 이벤트 연결, 당첨번호 표시, 첫 `render()` |
| `renderLatestDraw()` | ② 지난주 당첨번호 카드 그리기 (+ 최신 회차 확인 문구) |
| `getExpectedRound(today)` | 날짜로 최신 회차 계산 |
| `setMode(mode)` | 모드 전환, 버튼·안내 문구 갱신 |
| `toggleNumber(n)` | 현재 모드에 따라 번호 선택/해제 (F2 규칙 적용) |
| `addManualGame()` | 수동 게임 추가 |
| `removeManualGame(index)` | 수동 게임 삭제 |
| `fillRandom(base)` | `base`를 고정하고 나머지를 랜덤으로 채운 정렬 배열 반환 |
| `generate()` | 비어 있는 줄만 채우기 (F4) |
| `resetRow(index)` | 한 줄 초기화 |
| `copyRow(index)` | 한 줄 번호를 클립보드에 복사 |
| `copyFallback(text, done)` | clipboard API를 못 쓸 때 대신 복사 |
| `resetAll()` | 전체 초기화 |
| `ballHtml(n, isFixed)` | 공 하나의 HTML (빈 칸 포함) |
| `ballColorClass(n)` | 번호대별 색 클래스 |
| `render()` | 번호판, 선택 현황, 수동 게임 목록, 생성 결과 다시 그리기 |
| `showMessage(text)` | 경고·안내 메시지 표시 (Bootstrap `toast`, 없으면 `alert`) |

- 목록 안의 삭제·줄 초기화 버튼은 `data-index` 속성을 달고, 부모 요소 하나에 이벤트를 위임해서 처리한다 (`render()`로 다시 그려도 동작하도록).

## 8. 예외 처리

- [ ] 수동 번호 7, 14로 게임을 추가하고 생성하면 A줄이 "반자동"이고 7, 14가 파란 테두리로 들어 있다.

- [ ] C줄만 초기화하고 다시 생성하면 C줄만 바뀌고 A, B, D, E는 그대로다.
